# همگام‌ساز اکسل ← سایت

هر بار فایل اکسل را **Save** کنید، همه‌ی شیت‌های آن (به‌جز `data base` و شیت‌های پنهان) در صفحه‌ی **«اکسل»** سایت به‌روز می‌شود.

```
Excel (Save) → publish.py → Supabase (excel_sheets / excel_chunks) → صفحه‌ی «اکسل» (به‌روزرسانی زنده)
```

- شیت‌های **ثبت** (فویل، برش، آنیل، باسکول ضایعات، گام روغن، علامت و پارگی) به‌صورت جدول با جستجو و صفحه‌بندی نمایش داده می‌شوند.
- شیت‌های **گزارش** (داشبورد، مدیریتی، ماهانه، تولید روزانه، تنظیمات) عین خود شیت (ادغام سلول‌ها، رنگ‌ها) نمایش داده می‌شوند. این‌ها همان ماه و تاریخی را نشان می‌دهند که موقع Save در اکسل انتخاب بوده.
- نمودارهای اکسل فعلاً منتقل نمی‌شوند.
- فقط کاربران واردشده‌ی مجاز می‌بینند (RLS)؛ داده‌ی اکسل هرگز در فایل عمومی گیت‌هاب نیست.

## نصب (یک‌بار)

1. **دیتابیس:** در Supabase > SQL Editor فایل `supabase/excel_schema.sql` را اجرا کنید و سه مرحله‌ی انتهای همان فایل را انجام دهید
   (ساختن کاربر ناشر، ثبت او در `excel_publishers`، و ثبت بینندگان در `excel_viewers`).
2. **پایتون:** روی کامپیوتری که فایل اکسل رویش است Python 3.8 به بالا نصب کنید (هنگام نصب «Add Python to PATH» را بزنید). چیز دیگری لازم نیست.
3. `config.example.json` را کپی کنید با نام `config.json` و مقدارها را پر کنید (مسیر فایل اکسل، آدرس و کلید Supabase، ایمیل و رمز کاربر ناشر).
   فایل `config.json` رمز دارد و در `.gitignore` است؛ آن را در گیت‌هاب نگذارید.
4. اجرای تست: `python publish.py --once` (باید «تمام شد» بنویسد)، بعد در سایت صفحه‌ی «اکسل» را باز کنید.

## استفاده‌ی روزانه

- `run_publisher.bat` را اجرا کنید و پنجره را باز بگذارید؛ با هر Save منتشر می‌شود (حدود ۱۰ تا ۳۰ ثانیه بعد).
- برای اجرای خودکار با روشن‌شدن ویندوز: میان‌بر `run_publisher.bat` را در پوشه‌ی `shell:startup` بگذارید.
- فقط شیت‌هایی که تغییر کرده‌اند ارسال می‌شوند (مقایسه با هش محتوا).

## دستورها

| دستور | کار |
|---|---|
| `python publish.py --once` | یک بار منتشر کن |
| `python publish.py --watch` | منتشر کن و فایل را زیر نظر بگیر |
| `python publish.py --force --once` | همه‌ی شیت‌ها را دوباره بفرست |
| `python publish.py --dry-run out` | به‌جای ارسال، JSON را در پوشه‌ی `out` بنویس (برای آزمایش) |

## تنظیم شیت‌ها (اختیاری)

در `config.json`:

```json
"sheets": {
  "تنظیمات": { "kind": "skip" },
  "گام روغن": { "kind": "table", "keys": ["مقدار"] }
}
```

`kind`: `report` (عین شیت) یا `table` (جدول داده) یا `skip`. `keys` نام ستون‌هایی است که اگر خالی باشند آن ردیف نمایش داده نمی‌شود.

## عیب‌یابی

- «ورود ناشر ناموفق»: ایمیل/رمز کاربر ناشر یا کلید Supabase را بررسی کنید.
- «excel_sheets … ناموفق»: SQL اجرا نشده یا کاربر در `excel_publishers` ثبت نشده است.
- «فایل قفل است»: چند ثانیه صبر کنید؛ برنامه خودش دوباره تلاش می‌کند.
- صفحه‌ی «اکسل» در منوی سایت نیست: کاربر باید ویرایشگر باشد یا در `excel_viewers` ثبت شود، و حداقل یک بار منتشر شده باشد.
